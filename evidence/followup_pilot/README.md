# 실제 임상시험 조건명 예비 시험 (2026-10-29)

300건 밖의 실제 데이터에서 두 가지를 확인한 예비 시험입니다. 현재 사전·판정·분석 엔진은 바꾸지 않았습니다. 정확도 평가가 아니며 임상 전문가 검토를 받지 않았습니다.

## 표본

- 출처: ClinicalTrials.gov API v2, 처음 등록일 2026-09-01~2026-09-30인 임상시험 4,214건 전체(`population_nct_ids.json`).
- 표본: `random.Random(20261029)`로 400건 추출, 조건명 932개(`sample_400_studies.json`). 원문은 적격 기준 중 포함 기준 부분입니다.
- 어려운 사례를 고르지 않은 무작위 표본입니다. 한 달·한 출처라는 한계가 있습니다.

## 시험 1. 현재 분석 엔진의 처리 현황

조건명과 포함 기준을 현재 엔진(`app/analyzer.mjs`, prototype-4)에 그대로 넣었습니다(`engine_run_932.json`, `engine_run_summary.json`).

| 결과 | 건수 | 비율 |
|---|---:|---:|
| 기존 개념에 연결(자체 개념·별도 개체 포함) | 38 | 4.1% |
| 보류 | 48 | 5.2% |
| 미등록 | 846 | 90.8% |

확인한 점:

1. **사전 범위:** 287개 개념 그룹으로는 실제 조건명의 약 9%만 알아봅니다. 대규모 처리에는 MONDO 등 전체 용어체계를 후보로 쓰는 단계가 필요합니다.
2. **"이름 (약어)" 표기:** 87건이 이 형식이었고, 그중 23건은 사전에 있는 질환인데 형식 때문에 미등록이 됐습니다(예: Non-small Cell Lung Cancer (NSCLC)).
3. **보류 규칙:** 사전이 알아본 86건 중 48건(56%)이 보류됐습니다. 28건은 조건명이 포함 기준 문장에 다시 나오지 않아서, 12건은 포함 기준에 동반 질환이 나열돼서 보류됐습니다. 300건의 정형 문장에 맞춘 적용 규칙이 실제 임상시험 구조와 맞지 않습니다. 다만 Asthma 연구의 참여자가 의료진인 경우처럼 보류가 맞는 사례도 있었습니다.
4. **질환이 아닌 조건명:** 미등록 표현 60개를 무작위로 골라 Claude가 분류한 결과 질환·상태 31, 시술 10, 대상 집단 2, 기타 17이었습니다(`unregistered_sample60_classification.json`, 단일 판정자 분류). 질환·상태 31개 중 MONDO 정확 일치 검색에 걸린 것은 6개입니다.

## 시험 2. 판단 기준 적용의 일관성

표본 932건에서 무작위 30건(`random.Random(42)`)을 골라, 300건 구축과 같은 절차(후보 조회 → 정의 비교 → 관계 → 처리 상태와 이유)로 판정했습니다. 판정자는 서로의 답과 엔진 결과를 보지 않은 Claude 하위 에이전트 2개입니다. 두 판정자는 같은 지침(`judgment/BRIEF.md`)과 같은 기본 후보(`judgment/pack.json`)를 받고, 필요하면 공개 API로 추가 조회했습니다.

| 측정 | 결과 |
|---|---|
| 처리 상태 일치 | 29/30 (97%), Cohen's kappa 0.94 |
| 개체 유형 일치 | 28/30 (93%), kappa 0.91 |
| 둘 다 개념 연결한 항목의 개념 일치 | 12/12 |
| 300건 사전과 겹친 질환 | 4건 모두 기존 판정과 같은 개념 |
| 인용 ID 존재 확인 | 169개 모두 공개 API에서 확인 |
| 기준이 부족하다고 표시 | 판정자 A 20건, B 17건 |

불일치와 부족한 기준:

- V05 Bundle-Branch Block: 포함 기준은 서맥으로 심박조율이 필요한 환자입니다. 한 판정자는 연결, 다른 판정자는 입력 충돌 보류로 판정했습니다. 문맥이 얼마나 달라야 충돌로 보는지 기준이 없습니다.
- 시술·측정 지표·교육 같은 조건명이 30건 중 절반 가까이였습니다. G07은 증상·생리 상태·사건만 다루므로 두 판정자 모두 가장 가까운 '별도 개체'를 골랐습니다. '적응증 범위 밖' 상태가 필요합니다.
- 조건명이 참여자를 설명하지 않는 경우(의료진 대상 Asthma 연구, 보호자 대상 Critical Illness 연구)를 다루는 기준이 없습니다.
- 질환이 아닌 개체에 외부 코드를 붙일지 정한 규칙이 없어 5건에서 코드 선택이 달랐습니다.

## 이 결과의 한계

- 두 판정자가 같은 모델(Claude)이라 같은 방향으로 판단할 수 있고, 일치율이 실제보다 높게 나올 수 있습니다. 사람이나 다른 모델과의 독립 평가가 아닙니다.
- 30건 중 16건이 비교적 판정이 쉬운 '질환 아님'이었습니다.
- 판정 지침 4단계에 오류가 있었습니다. Prolonged 같은 수식어를 개념에서 빼라고 적었지만, G03·G05와 K101·K102는 기간 수식어를 개념 이름에 남깁니다. V26 Prolonged Diarrhea에 영향을 줍니다(`judgment/comparison.json`의 known_brief_error).
- 연결 결과가 맞는지는 판정하지 않았습니다.
