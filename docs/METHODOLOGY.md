# 동의어 딕셔너리 구축 과정

!> **문제:** 같은 글자가 같은 질환은 아닙니다. 무조건 합치면 다른 질환의 근거가 섞이고, 흩어 두면 검색이 분산됩니다.
!> **가설:** 키워드만으로는 일관된 판단이 어렵고, 원문 문맥과 명시적 규칙이 필요합니다.
!> **실험(초기 탐색):** 작업자가 만든 30개 사례에서 키워드만 주면 12/30, 원문을 함께 주면 22/30이 당시 기준과 일치했습니다. 독립 평가는 아닙니다.
!> **결과:** 300행 → 287개 개념 그룹, 별칭 419건, 자체 개념 17행, 보류 2행.
!> **반례:** NAFLD 약어 누락과 질환명 수식어를 환자 조건으로 추출한 문제를 고쳤고, 의심스러운 원천 계층(CLL→ALL)은 병합에 쓰지 않았습니다.
!> **후속 연구:** 질환 개념과 환자 조건의 분리 비교, 독립 주석 평가셋, 한국어·KCD 연결이 남아 있습니다.

## 1. 문제 정의: 같은 글자와 같은 질환은 다릅니다

같은 질환의 이름이 여러 표현으로 흩어지면 검색과 집계가 분산됩니다. 반대로 같은 약어나 비슷한 이름을 무조건 합치면 다른 질환의 근거가 섞입니다. 목표는 제공된 300개 입력을 검토해, 같은 뜻으로 연결할 표현과 구별할 표현을 근거와 함께 남기는 것입니다.

예를 들어 CD는 원문에 따라 Crohn disease 또는 Celiac disease입니다. 추가 문맥이 없는 K009는 둘 중 하나를 고르지 않았습니다. 반대로 T2DM과 type 2 diabetes mellitus는 검토 후 하나의 개념 그룹에 연결했습니다. 제공된 normalized_condition은 300행 모두 키워드와 같았으므로 정답으로 사용하지 않았습니다.

## 2. 비교 사례: 기존 지식은 후보와 근거로 사용합니다

MONDO는 여러 질환 용어체계의 명칭과 연결을 통합합니다. NCIt는 암을 포함한 생의학 개념의 정의와 용어를 제공하고, MeSH는 문헌 색인을 위한 Descriptor·Concept·Term을 구별합니다. 후보 이름이 비슷하다는 사실과 원문의 의미가 같다는 판단은 다릅니다.

기존 MONDO 후보를 고정 릴리스와 대조한 뒤, 300행 전체에 NCIt·MeSH 후보 조회를 추가했습니다. 일부 소견에는 HPO를 보조 사용했습니다. 정의·부위·조직형·원인·개체 유형·바이오마커 범위를 비교하고, 애매한 명칭과 진단 기준은 공식 기관·학회 자료로 보강했습니다. 같은 원천을 재사용하는 여러 서비스를 독립 투표자로 세지 않았습니다.

## 4. 가설과 해결 방안: 문맥과 명시적 규칙이 필요합니다

설계 가설은 다음과 같습니다. **키워드 문자열만으로는 동의어를 일관되게 판단하기 어렵습니다. 원문 문맥과 판단 규칙이 필요합니다.** 문맥을 주면 항상 정답이 된다는 가정은 하지 않습니다. 키워드와 원문이 충돌하면 입력 오류 가능성부터 기록합니다.

1. 원본 번호·키워드·문맥·정규화 열을 보존합니다.
2. MONDO·NCIt·MeSH 등에서 비교할 후보를 찾습니다. 이름 검색은 후보 수집 단계입니다.
3. 후보의 정의와 원문의 의미 범위를 비교합니다. 같은 개념, 상하위 범위, 관련 개념, 동등성 미확정, 다른 개체를 구별합니다.
4. 같은 개념으로 판단한 입력만 개념 그룹에 연결합니다. 검토한 이름과 별칭만 검색 목록에 넣습니다.
5. 질환명 구성 요소와 원문의 추가 조건을 분리합니다. 같은 NSCLC 그룹이어도 전이·재발·치료 조건은 다른 행이나 새 검색어에 전파하지 않습니다.
6. 문맥 부족·입력 충돌은 보류하고, OR 표현은 논리식을 보존합니다. 모든 입력을 억지로 단일 코드에 넣지 않습니다.
7. 판정·출처·적용 조건을 기록한 뒤 그룹·별칭·비교 사례의 일관성을 검사합니다.

실제 판단 규칙과 예외는 [가이드라인 G01–G12](#materials/guidelines), CD·eczema·NSCLC·NAFLD/MASLD 등은 [판단 사례](#cases)에서 확인할 수 있습니다.

## 5. 실험과 현재 데이터 검증

### 원문 문맥을 추가했을 때의 변화

초기 탐색 실험에서 작업자가 만든 30개 사례를 같은 기록상 모델(claude-sonnet-5-5)에 조건별로 세 번 입력했습니다. A는 키워드만, B는 키워드와 원문을 제공했습니다. **당시 정답·채점 규칙 기준**으로 A는 매회 12/30(40%), B는 매회 22/30(약 73%)였습니다. 이 전체 수치는 현재 딕셔너리의 정확도가 아니며, 정책과 무관한 성능으로 해석하지 않습니다.

문맥의 역할을 설명하기 위해 결과를 본 뒤 고른 약어 7건은 다음과 같습니다. 키워드만 준 A 조건에서 모델은 7건 모두 매번 **판단 보류(ambiguous)**로 답했습니다. 원문을 함께 준 B 조건에서는 각 건을 세 번 모두 해당 질환으로 연결했습니다. A의 0/3은 보류 응답이 당시 채점 기준의 질환명 정답과 불일치했다는 뜻이며, 잘못된 질환을 선택했다는 뜻은 아닙니다. B는 각 건이 3/3으로 당시 허용 답과 일치했습니다.

| 사례 | 약어 | 원문에 추가한 단서 | 당시 허용 답의 예 |
|---|---|---|---|
| H01 | MS | 시신경염·뇌 탈수초 병변 | Multiple sclerosis |
| H02 | MS | 심초음파의 승모판 면적 감소 | Mitral stenosis |
| H03 | PE | CT 폐혈관조영으로 확인 | Pulmonary embolism |
| H04 | PE | 임신 20주 이후 고혈압·단백뇨 | Preeclampsia |
| H05 | DM | heliotrope rash·근위부 근력 저하 | Dermatomyositis |
| H07 | AS | 양측 천장관절염·염증성 요통 | Ankylosing spondylitis |
| H08 | AS | 대동맥판 면적 1.0 cm² 미만 | Aortic stenosis |

이는 문맥이 없을 때 보류했던 약어를 원문 단서로 해소한 관찰이며, 문맥이 약어 해석에 도움을 줄 수 있음을 보여줍니다. **사후 선택한 설명용 부분집합**이며, 7건을 세 번 반복한 21개 관측을 독립된 21문항으로 세지 않습니다. 문맥이 없는 DM(H06)은 이 표에 포함하지 않았습니다. 모델 하나, 작업자 작성 사례·정답, 일부 개발 개념 중복(H28)이라는 한계가 있어 독립 평가나 인과 효과의 입증으로 보지 않습니다.

전체 A/B/C/D 결과와 현재 정책의 차이는 이 문서 아래의 **초기 탐색 실험(구 정책 기준)**에 따로 보존했습니다. 입력 30건·프롬프트·12회 예측·당시 채점 결과를 제출 소스에 포함했으며 `python3 tools/score_legacy.py`로 모델 호출 없이 재채점할 수 있습니다.

### 현재 딕셔너리의 결과

| 구분 | 결과 | 의미 |
|---|---:|---|
| 제공 입력 | 300행 | 모든 원문을 보존 |
| 개념 연결 | 276행 | 연구 판단으로 선택한 외부 개념 |
| 자체 개념 | 17행 | 원문 범위는 정의했으나 동일 범위 외부 연결이 남음 |
| 별도 개체 | 4행 | 생리 상태·생애 단계·증상·사건을 구별 |
| OR 조건 | 1행 | K018의 복합 논리식 |
| 보류 | 2행 | K009 문맥 부족, K024 입력 충돌 |
| 개념 그룹 | 287개 | 질환군·소견·상태 등을 포함 |
| 별칭 연결 | 419건 | 원문별 연결 포함, 고유 검색 문자열은 404개 |

대표 외부 표준 ID가 있는 입력은 별도 개체 일부를 포함한 279행입니다. MONDO 250행, NCIt 18행, MeSH Concept 10행, HPO 1행을 대표로 선택했습니다. LOCAL 키를 사용하는 입력은 사건을 포함해 18행입니다. 이 수치들은 임상 정확도가 아닙니다.

### 현재 데이터에서 검증한 것

87쌍 비교에서 같은 개념·구별할 개념·문맥 조건의 일관성을 확인했습니다. 이 사례들은 규칙을 만들며 사용했으므로 독립 정답셋이 아닙니다. 교차 검토에서는 NAFLD 별칭 누락과 질환명 토큰·추가 조건 혼동 등을 발견하고 수정했습니다. K009·K024는 불확실성을 숨기지 않고 보류로 남겼습니다.

- XLSX 원문과 제출 데이터 300행의 일치, 원본 번호의 유일성.
- 개념 그룹·별칭·대표 ID·범위 관계의 일관성.
- CD·AML의 다의 후보, 보류와 OR 식의 비병합, HER2 양성/음성 구별.
- 이름 구성 요소와 추가 조건의 원문 구간, 기간·전이·재발·치료 정보의 보존.
- 공식 API 응답의 해시, 출처 연결, 브라우저 검색·필터·다운로드·문서 접근.

### 새 문장 분석의 구현 범위

[새 문장 분석 열기](#analyze). 기존 개념·검토한 별칭과 명시적 약어 정의를 대조하고, 일부 조건 구간을 분리하는 시제품입니다. 개념 연결과 원문 주장·조건 범위·적격성 미평가를 구별합니다. 일반적인 의학적 의미 추론이나 독립 정확도 검증을 마친 분류기는 아닙니다.

### 전체 입력의 실행·의존성 대조

[검증 리포트](#materials/audit)에는 별칭 조회 무결성, 전체 사전 기반 A, 행 출처 제거 B, 규칙·조건 감사 C를 구별했습니다. 원문 주장과 개념 연결, 조건 소유·범위, 적격성 미평가를 별도 축으로 제공합니다. 모든 행의 결과·이유를 다운로드할 수 있으며 미등록·미지원도 공개합니다. 300행으로 만든 정책을 재사용한 개발 대조이므로 독립 정확도가 아닙니다. [검증 리포트의 대조 방법](#materials/audit?section=method)을 제공합니다.

### 근거 자료와 재현 범위

MONDO는 2026-10-06 릴리스를 고정했고 NCIt 응답은 26.09d를 명시합니다. MeSH·HPO API가 릴리스 버전을 노출하지 않은 경우 조회 시각·원본 응답·해시로 구별했습니다.

제출 자료에는 사용한 MONDO 항목의 발췌와 공식 API 응답 676개, 원문 인용 기록, 각 파일의 해시를 포함했습니다. MONDO 발췌는 전체 온톨로지가 아니며 계층·xref를 자동 병합 규칙으로 쓰지 않습니다. 짧은 인용만 보존한 웹 자료는 전체 페이지를 저장했다고 표시하지 않습니다.

`data/records.json`은 근거를 대조해 작성한 판정을 고정한 스냅샷입니다. 빌드는 판정을 다시 의학적으로 추론하지 않고 무결성을 확인해 검색·화면·다운로드를 재생성합니다. 유료 모델·API 키·네트워크 없이 실행할 수 있습니다.

## 6. 반례: 발견한 문제와 적용 조건

| 발견한 문제 | 확인·수정 | 현재 적용 조건 |
|---|---|---|
| K116에 NAFLD 약어가 빠져 검색이 되지 않음 | 근거가 있는 약어를 추가하고 K117 MASLD와 관련 링크 제공 | 명칭 변경을 안내하되 정의 기준이 다른 두 범위를 자동 병합하지 않음 |
| MONDO의 CLL→ALL 등 의심 계층 | 고정 릴리스의 엣지를 확인하고 NCI/SEER 임상 설명과 분리해 판단 | K164 CLL 표현을 보존하며 계층만으로 동의어 병합·하위 포함 검색을 확장하지 않음. 외부 온톨로지 자체를 수정했다는 뜻은 아님 |
| K262 NTM의 MeSH 후보 정의가 CDC 설명과 충돌 | 누락 후보를 보완하고 M. leprae 포함·제외 차이를 경고로 기록 | 후보는 UNKNOWN, 원문 범위는 LOCAL로 유지. 폐 위치도 임의로 추가하지 않음 |
| 질환명에 포함된 수식어를 환자의 추가 조건처럼 추출 | 질환명 구성 요소와 원문 추가 조건의 역할을 분리 | 같은 개념의 다른 행이나 새 검색어에 환자 조건을 전파하지 않음 |

출처가 있다는 사실만으로 같은 뜻이라고 확정할 수는 없습니다. 정의 충돌은 경고와 관계 상태로 남기고, 근거가 부족하면 보류하거나 자체 개념으로 범위를 보존합니다.

### 기본 의미의 적용 범위

K238의 판막성 대동맥 협착과 K249의 폐기종은 공식 용례를 근거로 선택한 기본 의미입니다. 판막 위·아래 또는 피하 등 반대 문맥이 명시되면 재검토하도록 scope_assumptions에 기록했습니다. 새 문장에 이를 자동 적용하는 분류기를 검증했다는 뜻은 아닙니다.

원천 MONDO의 선택 구문, 현재 판정에서 확인한 문제, 외부 자료의 탐색 결과는 [분류 기준과 적용 한계](#materials/methodology?section=counterexamples)에 구별해 정리했습니다. 외부 기준선과 잠정 임상시험 라벨은 현재 사전의 정확도 지표가 아닙니다.

### 1. 원천 용어체계에서 재검토할 관계

#### 같은 릴리스의 정의와 계층을 함께 확인

고정한 MONDO v2026-10-06에서 B-cell chronic lymphocytic leukemia(MONDO:0004948)는 아래 항목들의 하위로 기록돼 있습니다.

- chronic leukemia
- neoplasm of mature B-cells
- acute lymphoblastic leukemia(MONDO:0004967)
- indolent B-cell non-Hodgkin lymphoma

같은 릴리스의 acute lymphoblastic leukemia 정의는 급성 발병과 lymphoblasts를 설명하며, 계층에는 neoplasm of immature B and T cells가 있습니다. 이 서술과 계층을 함께 보며 정합성 재검토 대상으로 삼았습니다. 위 관계의 존재는 원본에서 확인한 사실이며, 의학적 타당성을 독립 전문가가 확정한 결과와는 구별합니다.

```text
MONDO:0004948  B-cell chronic lymphocytic leukemia
  is_a → MONDO:0004949  neoplasm of mature B-cells
  is_a → MONDO:0004967  acute lymphoblastic leukemia

MONDO:0004967  acute lymphoblastic leukemia
  is_a → MONDO:0005168  neoplasm of immature B and T cells
```

이 계층을 그대로 따라 하위를 확장하면 ALL 아래에서 CLL 항목에 도달합니다. 현재 사전은 이런 관계만으로 동의어를 병합하거나 하위 포함 검색을 자동 확장하지 않습니다. [K164의 현재 판정](#records?record=K164)과 [G09](#materials/guidelines)에 이 구분을 적용했습니다. 원천 온톨로지를 수정했거나, 우리 프로그램이 임상 오류를 자동 탐지했다는 뜻은 아닙니다.

근거는 [MONDO 공식 고정 릴리스](https://github.com/monarch-initiative/mondo/releases/tag/v2026-10-06)와 [선택 항목의 원본 구문 발췌](../evidence/boundary_checks/mondo_hierarchy_excerpt.json)입니다. 전체 OBO의 SHA-256은 다음과 같습니다.

```text
2631e8e165d41def1a46749adb1ce0a336c8aba7f6bc0978729592cee8fed60b
```

발췌는 전체 계층을 포함하지 않습니다. 다른 릴리스의 상태는 이 기록만으로 판단하지 않습니다.

### 2. 현재 판정에서 확인한 문제와 적용 조건

#### 검토 중 발견하고 반영한 내용

| 사례 | 확인한 문제 | 현재 처리와 근거 |
|---|---|---|
| NAFLD 별칭 | 개념은 있지만 약어 연결이 빠져 검색되지 않았음 | 근거 있는 별칭을 추가하고 MASLD는 별도 관련 개념으로 안내합니다. [사례](#cases/masld) |
| NTM 후보 | 누락 후보를 보완했으나 MeSH 정의의 균 목록과 CDC 설명이 충돌 | 후보를 UNKNOWN으로 남기고 LOCAL 범위를 보존합니다. [K262](#records?record=K262) |
| 질환명 수식어 | 이름 구성 요소를 환자의 추가 조건으로 중복 취급할 위험 | 이름 구성 요소와 관찰 구간을 구별합니다. [K011](#records?record=K011) |
| NSCLC 추가 조건 | 같은 개념 연결을 환자 조건 전체의 일치로 오해할 위험 | 전이·이전 치료는 K010에 보존하고 다른 입력에 전파하지 않습니다. [사례](#cases/nsclc) |

위 내용은 현재 데이터의 검토·수정 기록입니다. 87쌍 비교와 파일 검증은 일관성을 확인하며 독립 임상 정확도를 입증하지 않습니다.

#### 기본 의미를 적용할 수 있는 범위

| 입력 | 현재 선언한 기본 의미 | 재검토가 필요한 원문 |
|---|---|---|
| K238 Aortic stenosis | 공식 용례에 따른 판막성 대동맥 협착 | supravalvular·subvalvular 등 판막 위·아래 위치를 명시 |
| K249 Emphysema | 공식 용례에 따른 폐기종 | subcutaneous 등 피하·비폐성 위치를 명시 |

이 조건은 이미 scope_assumptions의 override_if에 기록돼 있습니다. [기본 의미 사례](#cases/sense)에서 원문과 후보를 확인할 수 있습니다. 반대 문맥은 기본 연결의 적용 범위 밖이며 재검토 대상입니다. 이번 보강에서 새 문장에 적용하는 자동 판정기나 추가 경계 실험을 실행한 것은 아닙니다.

#### 과거 실험 자료

과거 실험의 작업 정의·라벨과 현재 사전 정책의 차이는 [초기 탐색 실험](#materials/methodology)의 보조 섹션에서만 해석합니다. 해당 점수를 현재 판정의 정확도로 사용하지 않습니다.

## 7. 후속 연구와 한계

현재 결과는 연구용 판정이며 임상 전문가 승인은 0건입니다. 독립 주석자가 만든 정답셋으로 정확도를 평가하지 않았습니다. 276행의 문맥은 추가 아형 정보가 없는 템플릿입니다. 일부 용어에는 기본 의미와 예외를 선언한 정책이 적용됩니다. LOCAL은 외부 코드가 세상에 없다는 주장이 아니며, 동의어 목록의 완전성도 보장하지 않습니다.

우선 후속 과제는 보존한 질환 개념과 원문별 조건을 분리해 비교하는 표현을 설계하고 검증하는 것입니다. K010·K011의 구간 보존을 출발점으로 사용하되 질환명 구성 요소를 환자 추가 조건으로 옮기지 않습니다. 평가에는 전문가의 독립 주석, 정책을 먼저 고정한 신규 자료와 개념·환자 조건의 별도 지표가 필요합니다. 구체적인 문제·기존 근거·첫 단계·검증 방법은 [후속 연구](#materials/methodology?section=future)에 정리했습니다. 판정 변경 이력과 다중 사용자 검수를 추가하면 유지·보수에도 활용할 수 있습니다. 명시적 문서 정의를 이용하는 약어 해소와 일부 조건 구간 추출은 시제품으로 구현했습니다. 증상 기반의 일반적인 약어 추론, 환자별 진단·치료 적격성 판정, 완성된 임상 속성 추출기, 한국어 KCD 매핑은 현재 구현 범위 밖입니다.

### 후속 연구의 실행 범위와 검증 방법

F1·F3의 일부는 [새 문장 분석](#analyze) 시제품으로 구현했습니다. 나머지 기능과 독립 성능 평가는 후속 과제로 구별합니다.

| 제안 | 문제와 기존 근거 | 첫 단계 | 검증 방법 |
|---|---|---|---|
| F1. 질환 개념과 원문별 조건을 분리해 표현·검증 | K010·K011은 전이·재발·이전 치료 구간을 보존합니다. 같은 기본 개념이 환자 조건 전체의 일치를 뜻하지 않습니다. | **일부 구현:** 새 원문의 전이·재발·이전 치료 등 지원 패턴을 구간으로 추출하고 이름 구성 요소와 구별합니다. 질환별 조건 배정과 조건 간 적격성 비교는 남아 있습니다. | 독립 주석을 마련한 뒤 개념만 비교한 방식과 조건을 함께 비교한 방식의 잘못된 동일성 판단을 평가합니다. |
| F2. 원천 관계의 검토 목록과 릴리스 검사 | 위 CLL→ALL 관계처럼 사용 전 재검토할 원천 구문이 있습니다. | 릴리스·항목·검토 상태·근거를 가진 목록을 만들고 해당 구문의 변화를 확인합니다. | 원천 관계가 변경될 때 검토 대상을 알리고, 향후 계층 확장은 검토된 관계만 사용하는지 검사합니다. |
| F3. 문서 단위 약어 해소 | CD·AML은 문맥이 필요하며 외부 문자열 기준선에도 약어 문제가 관찰됩니다. | **일부 구현:** 긴 이름(약어) 정의를 기존 개념과 대조하고, 등록된 단일 의미 별칭과 구별합니다. 정의 충돌은 보류하며 증상만으로 의미를 추론하지 않습니다. | 노출 이력을 확인한 미사용 자료에서 불일치·보류·coverage를 함께 평가합니다. 허용할 trade-off도 평가 전에 정합니다. |
| F4. 독립 평가셋 | 현재 87쌍과 초기 30건은 구축 작업자가 작성한 사례입니다. | 새 자료에 별도 주석자 2명이 독립 주석하고 불일치를 조정합니다. | 개념 연결과 환자 조건 비교를 별도로 평가하며, 단위·분모·미채점·신뢰구간을 공개합니다. |
| F5. 한국어 표현과 국내 코드 연결 | 현재 제공된 입력과 별칭은 주로 영어입니다. | 한국어 표준명·별칭과 KCD 후보의 범위·버전을 검토합니다. | 별도 한국어 질의셋으로 검색 범위와 잘못된 연결을 평가합니다. |

F1은 현재 보존한 조건 구간을 실제로 재사용·비교하는 방향입니다. 임상 적응증 전체를 하나의 공식으로 정의하는 주장은 아닙니다. HER2·acute·chronic처럼 질환명 자체를 제한하는 정보를 모두 환자 추가 조건으로 이동하지 않습니다. 명시적 문서 정의에 따른 약어 해소와 일부 조건 구간 추출은 시제품에서 실행할 수 있습니다. 일반적인 문맥 추론, 여러 질환에 대한 조건 배정, 환자별 적격성 판정은 현재 구현 범위 밖입니다. 개발·반례 검사와 독립 성능 평가의 차이는 [구현·검사 문서](#materials/methodology)에 기록했습니다.

### 현재 실행 규칙의 경계와 대조

새 문장 분석은 개념 식별·원문 주장·조건 소유와 범위·적격성 미평가를 구별합니다. 반례를 재현해 non-small 변형, 원문 근거 미확인, 부정 문형, 관계 미검토, OR 구조를 보강했습니다. [전체 A/B/C 대조](#materials/audit)에 미지원과 검토 필요를 포함한 모든 행을 공개합니다. 행 출처 제거 대조에도 전체 개념 목록과 전역 정책이 남으므로 독립 평가가 아닙니다.

### AI 활용

AI를 후보 탐색·판정 초안·문서화·코드 작성·교차 검토에 사용했습니다. 두 AI의 일치를 정답으로 채택하지 않고 원문과 공식 근거를 대조했습니다. 모델 간 검토는 블라인드 또는 임상 전문가 검증이 아닙니다. 판정과 근거를 웹과 파일에서 검토할 수 있게 공개했습니다.
