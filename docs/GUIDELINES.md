# 질환 동의어 판정 가이드라인

적용 대상은 제공된 키워드 300행이다. 기본 판정 단위는 **source_id로 식별한 원문 레코드**이며, 표면형·임상 개념·환자 조건·외부 코드를 구별한다. 모든 판정은 근거를 남긴 연구 판단이고 전문가 승인 또는 독립 임상 정확도 평가를 의미하지 않는다.

## 판정 절차

1. 원문과 입력 정규화 열을 보존한다. 제공된 normalized_condition은 300행 모두 keyword와 같으므로 정답으로 사용하지 않는다.
2. 문맥에 명시된 긴 이름, 장기·원인·조직형·수용체 상태·질환 경과·치료 조건을 확인한다. 템플릿 문맥을 실제 추가 정보처럼 쓰지 않는다.
3. 질환, 질환군, 소견, 증상, 생리 상태, 사건 중 어떤 개체인지 판단한다.
4. MONDO·MeSH·NCIt에서 후보와 정의를 찾고 소견에는 HPO를 선별 사용한다. 애매한 기준·구명칭은 공식 기관·학회·원 논문으로 대조한다.
5. 후보마다 원문 대비 범위 관계를 정한다. 같은 검색 결과라는 이유로 동의어로 만들지 않는다.
6. 같은 기본 개념으로 판단한 입력만 같은 concept_key로 묶는다. 임상 조건은 원래 행에 보존한다.
7. 승인할 별칭과 관련·상하위 관계를 분리한다. 코드 활성 상태·출처·조회 버전·변경 이력을 기록한다.
8. 문맥 부족·입력 충돌은 명시적으로 보류한다. 의미가 분명하나 표준 코드가 맞지 않으면 범위를 정의한 LOCAL 개념을 사용한다.

## 범위 관계

관계 방향은 항상 **원문 → 후보**다.

| 관계 | 뜻 | 사용 예 |
|---|---|---|
| EXACT | 이 사전에서 선택한 임상 개념 범위가 같음 | Type 2 diabetes → type 2 diabetes mellitus |
| BROADER | 원문이 더 넓음 | 부위 미지정 NTM 감염 → 폐 NTM 감염 |
| NARROWER | 원문이 더 좁음 | 축성 척추관절염 → 척추관절병증 일반 |
| RELATED | 관련되지만 동일 범위로 연결하지 않음 | NAFLD 과거 개념 → MASLD 현행 개념 |
| UNKNOWN | 외부 정의·범위 동등성 근거가 부족하거나 충돌 | sepsis → 과거 SIRS 중심 후보 정의 |
| DIFFERENT_ENTITY | 다른 개체 또는 원문과 다른 의미 | 문맥의 AML 신장 종양 → AML 백혈병 검색 후보 |
| COMPONENT | 논리식의 구성 개념 | MDS OR AML의 두 분기 |

EXACT는 질환 개념 수준의 판정이며 개별 환자의 진단 검사·치료 적격 조건이 모두 같다는 뜻이 아니다. `data/comparisons.json`의 SAME_BASE_CONCEPT 등은 검토 사례 간 비교 표기이며 온톨로지 공리나 자동 병합 지시가 아니다.

## G01 — 원본과 오류 흔적을 보존

source_id, keyword, raw_context와 제공된 normalized_condition을 수정하지 않는다. K024는 keyword의 eczema와 raw_context의 plaque psoriasis가 충돌하므로 어느 필드를 고칠지 추측하지 않고 HOLD_SOURCE_CONFLICT로 둔다. 후속 정정 시에도 원본과 정정 이력을 함께 보존한다.

## G02 — 다의 약어는 문맥에 묶음

CD는 K007에서 회결장 염증·누공 문맥의 크론병, K008에서 글루텐 관련 장질환 문맥의 셀리악병으로 잠정 해석한다. K009에는 그 단서가 없어 HOLD_AMBIGUOUS다. AML은 K011/K012의 긴 이름을 기준으로 백혈병과 신장 혈관근지방종을 구별한다. 검색 순위·빈도·다른 행의 정답을 전파하지 않는다.

CD·AML 별칭 조회는 여러 개념을 반환한다. 명확한 문맥 없이 자동 선택하지 않는다. T1DM/T2DM처럼 관행적 긴 이름이 확인되는 약어는 그 근거를 기록하고 숫자 정보를 보존한다.

## G03 — 범위 제한을 무단으로 바꾸지 않음

장기·부위·조직형·원인·유전형·양성/음성·급성/만성·중증도·경과를 비교한다. 일반 cancer를 검색에 함께 나온 carcinoma로, Addison disease를 자가면역 아형으로, 부위 미지정 NTM 감염을 폐 감염으로 좁히지 않는다. functional·axial·severe 같은 제한도 제거하지 않는다.

K014는 후보 정의가 원문에 없는 ER 음성을 요구해 일반 HER2 양성 암의 로컬 범위를 유지한다. K145는 자궁 위치를 자궁 체부로 강화하지 않는다. 표준 임상 용례를 채택하는 경우는 G08에 따라 별도 의미 정책과 반례 문맥을 명시한다. 단순히 가장 넓은 색인 정의를 고르는 것도 자동적인 정답은 아니다.

## G04 — 표기 일치와 의미 판정을 구별

대소문자·공백 차이는 안전하게 정리하되 숫자·양성/음성 부호는 유지한다. 표기 정리만으로 임상 동등성을 확정하지 않는다. 같은 선호명·ID·검색 결과라도 정의·개체 유형을 확인한다.

MeSH는 Descriptor와 Concept을 구별하고 실제 Term 소속을 확인한다. 같은 Concept 안에 있더라도 엄밀한 임상 구분이 필요한 경우 정의·반례를 대조한다. K070은 MeSH chondrocalcinosis 범위와 증상성 pseudogout을 별도 판정한다. 반면 MONDO의 같은 명칭에는 급성 발작 정의가 있어 해당 후보는 명칭–정의 충돌로 UNKNOWN이다. 같은 라벨의 다른 출처에 관계를 복사하지 않는다. NCIt의 전체 FULL_SYN 목록을 일괄 복사하지 않는다.

K076은 NIAMS가 명시하는 giant cell arteritis/temporal arteritis 명칭 관계를 인정한다. NCIt 정의의 ‘주로 침범’은 ‘그 부위만 침범’이 아니므로 전신 질환을 특정 동맥에 한정해 해석하지 않는다.

## G05 — 질환 개념과 환자 조건을 함께 보존

K010과 K131의 기본 NSCLC 개념은 같지만 K010의 전이·이전 치료 조건은 삭제하지 않는다. K011의 재발, K012의 TSC 동반, K006의 인슐린 필요 조건도 원래 행의 관찰 구간에 남긴다. 한 행의 조건을 같은 질환의 다른 행이나 새 검색어에 상속하지 않는다.

질환 정의에 특정 유전자·빈도·기간·검사값이 등장해도 입력 환자의 실제 관찰값으로 생성하지 않는다. CML 정의와 환자의 BCR-ABL1 검사 결과는 다르다. 양성·음성처럼 아형을 정의하는 정보는 개념 선택에도 반영한다.

원문에 있는 토큰도 역할을 구별한다. K011의 acute는 acute myeloid leukemia라는 질환명 구성 요소로 concept_name_components에 남기고, Relapsed는 추가 상태로 clinical_attributes에 남긴다. K017의 Chronic은 이름 구성 요소이고 실제 more than 3 months 구간은 기간 조건이다. 이름 구성 요소를 환자 추가 조건 필터로 사용하지 않는다. 이는 검토한 이름 목록에 한정한 규칙이며 일반 임상 정보 추출기의 완전성을 주장하지 않는다.

이 원칙은 속성 유형 전체에 적용한다. 선택한 개념 표시명 또는 검토한 이름 변형 안에 포함된 K138의 Castration-resistant, K247의 Severe, K266의 Recurrent와 K014·K015의 HER2 표기도 이름 구성 요소로 구별한다. 개념을 제한하는 의미와 원문 위치를 보존하며 같은 수식어를 환자의 별도 추가 조건으로 중복 취급하지 않는다. 선택한 이름 밖에서 명시된 치료·경과 조건은 추가 문맥으로 유지한다.

## G06 — AND/OR는 논리식

K018은 문맥상 MDS 또는 AML 중 하나가 적격한 식이다. 별도로 존재하는 MDS/AML라는 질환 개념을 단순 문자열 때문에 선택하지 않는다. 전체 식을 두 질환의 별칭으로 등록하지 않고 구성 개념만 참조한다.

## G07 — 질환 외 개체를 보존

정상 임신·폐경·갈증·SRE는 생리 상태·생애 단계·증상·사건으로 구분한다. 임상 적응증에 쓰일 수 있으므로 삭제하지 않는다. 원인 질환을 추론하지 않으며 Finding으로 분류된 항목을 모두 버리지 않는다.

외부 semantic type은 근거 필드다. K197의 갑상선 결절을 NCIt 유형만 보고 암으로 바꾸지 않는다. 요실금 임상 소견과 요실금 설문·PRO/CTCAE 평가 항목은 다른 개체다. HPO 표현형 연결은 그 소견을 일으키는 질환으로의 변환이 아니다.

## G08 — 명칭·정의 버전과 표준 용례를 구별

PBC의 primary biliary cirrhosis/cholangitis, 2026년 PCOS/PMOS처럼 같은 임상 상태의 명칭 관계를 공식 근거로 확인하면 별칭을 연결한다. 과거 표현은 보존한다. NAFLD/MASLD처럼 기준 검토가 필요한 경우는 명칭 변경과 환자군 동등성을 분리한다.

이번 사전은 K116의 과거 기준 범위와 K117의 현행 기준 범위를 유지하는 정책을 택했다. NAFLD/MASLD 검색은 서로를 related_matches로 안내하며 직접 별칭 일치 candidate_concept_keys와 구별한다. related_matches를 EXACT 또는 자동 병합에 사용하지 않는다. 명칭 변경에 기준 차이가 동반된 경우를 구별하는 선택이며 유일한 가능한 개념 모델이라고 주장하지 않는다.

진단 기준 변경을 동의어에서 환자 규칙으로 복사하지 않는다. EoE의 PPI 치료 실패 조건, sepsis의 과거 SIRS·혈중 미생물 조건, 섭식 장애의 오래된 성별·무월경 설명 등이 그 예다. K260 Long COVID/PASC는 명칭 연결을 유지하지만 NCIt의 기간 정의와 현행 CDC 기준 차이를 definition_warnings로 남긴다. K117의 MASLD 코드명 연결도 출처의 모든 과거 정의 문장을 현행 진단 기준으로 승인한다는 뜻이 아니다.

표준 임상 용례를 채택할 때에는 **선택한 의미와 반례 문맥**을 명시한다. K108의 무수식 pancreatic insufficiency에는 MeSH/NCIt의 외분비 용례를 적용하되 내분비 기능을 명시한 문맥에는 적용하지 않는다. K093도 식도 이완불능증 의미를 명시한다. K238은 AHA의 aortic stenosis 용례에 따라 판막성 의미를 적용하되 판막 위·아래 협착이 명시되면 무효화한다. K249는 MedlinePlus의 emphysema/pulmonary emphysema 명칭 관계에 따라 폐 의미를 적용하되 피하 등 비폐성 위치가 명시되면 무효화한다. 이는 다수결이나 숨은 환자 사실 추론이 아니라 검토 가능한 사전 의미 정책이며 scope_assumptions에 기록한다. 단어 조회는 해당 후보와 조건을 반환하며 새 문맥에 자동 적용하지 않는다.

## G09 — 코드·계층·개념 의미를 별도로 검증

ACTIVE는 코드 상태 확인이다. 계층·xref·공식 EXACT 문자열만으로 임상 의미를 승인하지 않는다. K134의 폐기된 NCIt 코드는 선택하지 않는다. CLL→ALL, acquired PV→familial polycythemia 등 기존 MONDO의 의심 계층은 자동 포함 검색에 쓰지 않는다.

선택한 ID가 유용하더라도 그 출처의 모든 정의 문장·계층·별칭을 동시에 승인한 것은 아니다. 잘못된 후보·과거 정의·활성 상태를 결과에서 숨기지 않는다. 명칭–정의–계층 충돌, 정의 버전 차이, 위험 인자의 필수 조건 오해는 definition_warnings에 구별해 기록한다. 같은 concept_key의 입력은 동일한 entity_type을 가져야 하며 충돌하면 빌드를 중단한다. 예를 들어 K010/K131의 NSCLC는 모두 DISEASE_GROUP이다.

K201은 NCIt의 주 정의와 NICHD 대체 정의의 범위가 다름을 함께 표시한다. K262의 MeSH NTM 후보는 CDC의 균 배제 범위와 정의 목록이 충돌해 UNKNOWN으로 남긴다. K190의 IIa 라벨과 유전 질환 정의도 포함 관계를 단정할 근거가 충분하지 않아 UNKNOWN으로 기록한다. 후보 발견·코드 활성·의미 범위 동등성은 각각 다른 판단이다.

## G10 — LOCAL은 내부 임상 범위

의미가 분명해도 동일 범위의 외부 코드를 확보하지 못할 수 있다. LOCAL은 서비스 내부 개념이며 공식 표준 코드가 아니다. 상위 코드로 대체해 코드 부착률을 높이지 않는다. 원문 의미 미해결과 외부 코드 정합성 미완료를 다른 필드로 기록한다. Sepsis-3 범위를 정의한 K269는 유효한 로컬 개념이며 원문 의미 보류와 다르다.

## G11 — 출처와 변경 이력을 보존

매핑마다 출처 체계·ID·관계·버전·정의 위치·확인 시점·원본 응답 해시를 남긴다. MeSH/HPO API가 릴리스 버전을 노출하지 않으면 확인하지 않은 버전을 추정하지 않는다. MONDO·MedGen 등 원천을 통합하는 서비스를 독립 투표자로 세지 않는다.

선호명이나 코드를 바꿀 때 이전 판단 파일·SHA-256·전후 선택·이유를 보존한다. 두 AI의 동의는 근거가 아니며 전문가 승인으로 표현하지 않는다.

## G12 — 검토 완료·외부 정합성·정확도를 구별

300행을 모두 사례별 연구 검토했다는 사실, 표준 연결 수, 로컬 개념 수, 보류 수, 동의어 그룹 수를 구별한다. K009/K024의 보류도 입력을 검토하고 근거 있게 내린 판정이며, 해결됐다는 뜻은 아니다.

검증용 비교 사례와 회귀 검사는 현재 구축 규칙의 일관성을 확인한다. 이 입력으로 규칙을 고친 뒤 같은 입력의 통과율을 독립 정확도로 보고하지 않는다. 기존 LLM 개발·홀드아웃 실험도 현재 최종 사전의 임상 정확도를 증명하지 않는다.
